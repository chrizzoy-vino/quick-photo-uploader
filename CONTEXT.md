# Quick Photo Uploader

A web app that lets you quickly upload and view photos and videos in a shared album, without a login. The album link is typically distributed via messenger (e.g. WhatsApp).

## Language

**Album**:
A shareable collection of media items addressed by a slug. Comes into existence implicitly with the first successful upload and stops existing once the last media item is removed from it — regardless of whether that happened through the UI or directly on the server.
_Avoid_: folder

**Slug**:
The URL path segment that uniquely identifies and addresses an album (e.g. `album-test` in `.../album-test`). Lowercase, alphanumeric plus hyphens; reserved system paths are excluded.
_Avoid_: album name, folder name

**Media item**:
A single uploaded photo or video within an album. Consists of an original and a thumbnail, and carries the display name of the uploader at the time of upload.
_Avoid_: file, asset, photo (when a video could also be meant)

**Original**:
The media item stored at full resolution, exactly as uploaded (after any format conversion needed for display). Offered for download.

**Thumbnail**:
A smaller, server-generated representation of a media item for fast display in the gallery. May be created with a delay relative to the original.
_Avoid_: preview

**Gallery**:
The view that displays all media items of an album, including sorting, view mode (list/grid), and multi-select for deletion.
_Avoid_: overview, list (list is only one of the gallery's view modes, not a synonym for it)

**Display name**:
The name associated with an uploader, shown on every media item they upload. Randomly generated by default, changeable by the uploader, applies per device (not per album), and is frozen onto each media item at the time of upload — a later name change only affects future uploads.
_Avoid_: username, profile name (there are no user accounts)

**Owner token**:
A secret generated per media item at upload time, stored only in the uploader's browser, that exclusively allows that uploader to delete that specific media item. Like the display name, it's fixed to the media item at upload time, but it is not proof of identity and serves solely as delete authorization — whoever loses their device/storage loses the ability to delete their own uploads.
_Avoid_: password

**Administrator**:
The role that logs in via the admin area and thereby may bypass all restrictions that apply to ordinary uploaders — in particular, deleting other people's media items or entire albums without an owner token. There is exactly one administrator identity for the whole installation, not individual admin accounts.
_Avoid_: admin (as a noun in running text), operator (that refers to the person running the server, not this app role)

**Admin area**:
The protected part of the app where the administrator can view all albums with metrics (file count, size, last activity) and delete media items or entire albums independent of any owner token.
_Avoid_: admin panel, backend, dashboard

**Duplicate**:
A file being uploaded whose content (file bytes, compared via hash) exactly matches a media item already present in the same album — regardless of filename. The comparison applies only within the same album; the same file in a different album is not a duplicate. A detected duplicate is not stored as a new media item; the upload is rejected, with a note on who the existing media item came from. A recompressed version of the same recording (e.g. after a WhatsApp forward) has different bytes and does not count as a duplicate.
_Avoid_: copy, duplicate file
