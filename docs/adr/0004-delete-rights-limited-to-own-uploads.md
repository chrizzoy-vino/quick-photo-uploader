# Delete rights limited to own uploads, administrator can delete anything

ADR-0001 deliberately rejected limiting delete rights to one's own uploads, to keep the app as simple as a shared folder. With live operation on a publicly reachable domain, the risk of other people's keepsakes being deleted accidentally or maliciously outweighs the earlier UX gain. We decided to restrict deletions to one's own uploads via an owner token, without introducing a login — the token is created at upload time and stored client-side only. The administrator can bypass this restriction via the admin area and delete any media item or entire albums (deleting an album technically means deleting all of its media items, see the Album definition in CONTEXT.md). Considered and rejected: a full login with user accounts (contradicts the core "no login" promise), attribution via display name (freely chosen and not forgery-proof, so unsuitable as proof of authorization).
