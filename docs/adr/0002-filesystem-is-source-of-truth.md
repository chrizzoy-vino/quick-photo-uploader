# The filesystem is the source of truth, not the database

Media items can disappear externally (`rm` on the server) without the app noticing, and an album must disappear as soon as it's empty. We decided that the database is only a lazily-maintained index, reconciled against the filesystem on every gallery view — a file missing from disk counts as deleted, an empty album as no longer existing. Considered and rejected: the DB as sole source of truth with soft deletes (would drift from reality after an external `rm`), a periodic reconciliation cron job (unnecessary operational overhead at this scale).
